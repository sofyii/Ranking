**Ранжирование русскоязычных поисковых результатов**

***Задача и данные***

Я решала задачу ранжирования фрагментов по поисковому запросу. Для каждой пары «запрос - фрагмент» требовалось предсказать число: чем оно больше, тем выше фрагмент в выдаче. Метрика — средний по запросам NDCG@10. Обучающая выборка содержит 31 530 пар для 3 042 запросов, тестовая — 13 507 пар для 1 305 запросов

Я работала с macOS, а обучение и предсказание запускала в Google Colab. Среда выполнения Colab — Linux с GPU NVIDIA T4

***Подготовка данных и проверка***

Я проверила уникальность id, отсутствие пересечения query_id между обучением и тестом, размеры групп, доли релевантных ответов по источникам и пропуски в столбцах. Для оценки качества разделила обучающую выборку по query_id с помощью GroupShuffleSplit: запросы в обучении и на проверке не пересекались

Для текстовых признаков я обрабатывала запрос, заголовок и текст фрагмента. Пропуски в текстах заменяла пустыми строками, article_char_count приводила к числу, а некорректные значения в итоговых признаках заменяла. Считала совпадения слов запроса с заголовком и фрагментом, положение первого совпадения, сходство TF-IDF по словам и символам. Добавила номер фрагмента, число фрагментов статьи, источник и относительные позиции кандидатов внутри запроса

***Промежуточные эксперименты***

Все приведённые ниже значения NDCG@10 получены на одном отложенном наборе запросов:

- BGE reranker без дополнительного обучения дал 0,925873. Его оценки я добавила в признаки для CatBoostRanker

- CatBoostRanker с текстовыми признаками и BGE дал 0,935893

- Я дополнительно обучила BGE с помощью LoRA и смешала его оценки с предыдущим решением. Результат вырос до 0,936766; на проверке лучшими оказались две эпохи и вес LoRA 0,3. Дополнительное добавление исходных оценок BGE результата не улучшило

- GigaEmbeddings отдельно дала 0,922313. При смешивании её оценок с предыдущим решением результат вырос до 0,938997 с весом GigaEmbeddings 0,4

- Я добавила оценку GigaEmbeddings и её положение среди кандидатов в признаки нового CatBoostRanker. Он дал 0,940673. При проверке смешивания лучшим оказался вес нового ранкера 1,0, поэтому для итогового предсказания используется именно он

Отдельно я пробовала запустить Qwen3-Reranker-4B, но загрузка не завершилась в сеансе Colab. Эта модель в итоговом результате не используется

***Итоговое решение***

Финальный CatBoostRanker использует текстовые признаки, метаданные, оценки BGE и GigaEmbeddings. Для выбора числа деревьев я обучала его на части запросов и проверяла на отложенных запросах; затем обучала модель на всей размеченной выборке. В итоговом прогнозе оценки CatBoostRanker переводятся в ранги внутри каждого запроса. Файл отправки содержит столбцы id,prediction

Локальное значение финальной модели — 0,940673 NDCG@10, результат отправки на платформе соревнования — 0,934207. Это разные оценки на разных наборах запросов
